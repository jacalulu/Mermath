# Art pipeline

All of the art was made in code. Nothing was drawn by hand or generated by an image model. This matters for the build: when you need a new scene, a new character or a new grotto item, you can make it the same way and it will match.

## How a picture gets made

1. **Draw it as SVG.** Python builds the picture from shapes and gradients: `chars.py` (characters and helpers), `scenes.py` and `frame.py` (scenery), `puppet.py` (the crab in pieces, the icons, the small props), `mpuppet.py` (the sisters in pieces).
2. **Rasterize it.** `render.py` opens each SVG in headless Chrome through Playwright and screenshots it, usually at 2x.
3. **Paint it.** `paint.py` repaints the raster with curved brush strokes in several sizes, largest first (the method from Hertzmann, "Painterly Rendering with Curved Brush Strokes of Multiple Sizes", 1998). Strokes follow the image gradients, and where the picture is flat they fan out from the light source.
4. **Cut it into layers.** Scenery is drawn as named layers (far kelp, mid kelp, foreground and so on) and each is painted on its own, with its outline rebuilt from the strokes so edges look painted too (`sprites2.py`, function `painted_alpha`). Characters are painted piece by piece with finer strokes and a clean, slightly roughened edge (`sprites.py`).
5. **Leave faces alone.** Eyes, brows, noses and mouths are separate layers that skip the paint pass, so they stay crisp.

## The scripts

| File | What it does |
|---|---|
| `chars.py` | Shared helpers and shapes; the earlier one-piece characters and shells |
| `scenes.py` | Scene-building class and props (kelp, rocks, coral, fish, sea stars); the six earlier flat scenes |
| `frame.py` | The Tide Pool and home scenes as named layers |
| `puppet.py` | The crab as pieces; the three painted icons; small props |
| `mpuppet.py` | The three sisters as pieces. `SISTERS` holds each one's colors and hairstyle (`long`, `buns`, `pigtails`) |
| `render.py` | SVG to PNG. `render.py name:scale:alpha ...` |
| `paint.py` | The brush-stroke pass and its presets (`tide_bg` is the one used for backgrounds) |
| `sprites.py` | Paints character pieces and icons |
| `sprites2.py` | Paints the Tide Pool scenery layers and props |
| `sprites3.py` | Paints the home scenery layers and the sisters (`sprites3.py scene sisters`) |
| `wordmark3.py`, `wordmark6.py`, `wordmark7.py` | The wordmark: lettering, the tail, the plus. `wordmark7.py t` builds the final one. |
| `icon7.py` | The app icon |
| `preview.py` | Renders the storyboard screens locally for checking |

`svg-sources/` has the vector source for every character piece, icon, prop and scenery layer, in case you want to edit a shape directly.

## Before you run anything

These scripts are exactly as they were run during design. They are a working reference, not a packaged tool.

- They need Python 3 with `numpy`, `opencv-python`, `scipy`, `Pillow` and `playwright`, and a Chrome that Playwright can launch.
- Several paths are hard-coded near the top of the files and will need pointing at your project: the output folder for finished art (`ART = '/home/claude/mermaid-art'` in `sprites.py` and `preview.py`), the Chrome path (`/usr/bin/google-chrome`), and the font paths in `wordmark.py` and `preview.py`.
- Working files go to an `out/` folder next to the scripts. Create it first.
- The wordmark needs the Fraunces variable font (from the `@fontsource-variable/fraunces` package). Baloo 2 is only needed by `preview.py` (and by an unused number-bubble variant inside `wordmark7.py`).
- The usual order is: write the SVGs (run the drawing script), rasterize (`render.py`), then paint (`sprites*.py`).

## Settings that define the look

Scenery backgrounds use the `tide_bg` preset in `paint.py`: brush radii 36, 18, 9, 4; a slight saturation lift (1.12); strokes that fan from a light source above the frame. Character pieces use radii 32, 16, 8, 4 with tighter thresholds, which is why they look one step cleaner than the scenery. Small props and the wordmark tail use radii around 10, 5, 3.

If a new piece looks too smeared, use smaller radii. If it looks too clean next to the scenery, use larger ones.

## Adding things

- **A new sister hairstyle or color:** edit `SISTERS` in `mpuppet.py`, run it, rasterize the changed pieces with `render.py name:2:1`, paint them with `sprite(...)` from `sprites.py`.
- **A new scene:** follow `scene_tide_layers()` in `frame.py`. Draw into named layers, rasterize each, paint each with `layer(...)` from `sprites2.py`.
- **A new grotto item or icon:** follow `icon_shell()` in `puppet.py`.
